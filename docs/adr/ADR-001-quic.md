# ADR-001: トランスポートに QUIC を使う

- **日付**: 2026-06-22
- **状態**: Accepted

## 決定

`quic-go` を使って QUIC でファイルを転送する。

## 理由

- TCP より接続確立が速い（0-RTT / 1-RTT）
- 複数 Stream を 1 接続で多重化でき、チャンク並列転送 (Phase 5) が自然に実装できる
- 組み込み TLS 1.3 で暗号化と認証が最初から備わる
- Head-of-Line ブロッキングがなくパケットロス時の性能劣化が小さい

## トレードオフ

- UDP ベースのため、一部のネットワーク環境（UDP ブロック）では使えない
  → fallback として TCP モードを Phase 6 以降で追加予定
