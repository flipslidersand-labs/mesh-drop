## [0.7.0] — 2026-08-23

### Added
- `feat(relay)` maxSessions configurable via `--max-sessions` / `MAX_SESSIONS` env (#327)
- `feat(relay)` Prometheus `/metrics` endpoint (#328)
- `feat(release)` GoReleaser v2 config with checksums, SBOM (syft/spdx-json), cosign keyless signing (#334)
- `feat(cli)` `meshdrop completion` shell completion subcommand (#362)
- `feat(relay)` GET `/health` endpoint (#306)
- `feat(nat)` Exponential backoff retry for STUN/Relay (#326)
- `feat(config)` `~/.meshdrop/config.yaml` auto-load with XDG_CONFIG_HOME support; `meshdrop config init` (#388)

### Fixed
- `fix(transfer)` Atomic rename via `.meshdrop.tmp` on receive — prevents incomplete files on abort (#359)
- `fix(transfer)` `filepath.Walk` → `filepath.WalkDir` to skip symlinks (#352)
- `fix(transfer)` `WalkDir` now accepts `ctx` and propagates cancellation to errgroup (#350)
- `fix(transfer)` `pipe.go` `SendPipe`/`ListenPipe` use `quicConfig()` instead of `nil` (#351)
- `fix(transfer)` TLS self-signed cert validity extended from 24h → 10 years (#324)
- `fix(transfer)` `acceptDirChunk` nil file-handle panic guard (#256)
- `fix(transfer)` Log errors from `dispatchConnToDir` goroutines (#358)
- `fix(transfer)` Log `checkpoint.finish()` flush errors (#360)
- `fix(webui)` `srv.Shutdown` with 5s context timeout — prevents hang on Ctrl-C (#354)
- `fix(webui)` `handleSend` uses `s.runCtx` for transfer cancellation (#254)
- `fix(relay)` Replace `panic` with error return in `randomCode` (#339)

### Security
- `security(webui)` Optional Bearer token auth via `--auth-token` (#387)
- `security(webui)` Per-IP rate limiting — HTTP 429, 30 req/min burst 10 (#367)
- `security(webui)` Security response headers: `X-Frame-Options`, `CSP`, `X-Content-Type-Options`, `Referrer-Policy` (#347)
- `security(webui)` `MaxBytesReader` 512 MiB on `handleSend` (#257)
- `security(webui)` RFC 6266 `Content-Disposition` filename escaping (#258)
- `fix(transfer)` Reject `Meta.Name`/`FileMeta.Path` containing control chars or null bytes (#325)

### CI / DX
- `ci` golangci-lint workflow (#280)
- `test` TLS bundle fingerprint verification unit tests (#355)
- `test` `DeriveChunkStreamKey` unit tests (#353)

## [0.2.0] — 2026-08-16

### Added
- Self-hosted relay server (`meshdrop relay`) with session codes
- NAT traversal via STUN + relay fallback
- File transfer resume (checkpoint-based, BLAKE3 hash verification)
- Pipe mode (`--pipe`) for stdin/stdout transfer
- Multi-chunk parallel transfer with configurable concurrency

### Security
- Noise_XX handshake with Trust-On-First-Use (TOFU) peer verification
- TLS self-signed certificate pinning (fingerprint verification)
- Chunk stream key derivation via `DeriveChunkStreamKey`
